Preguntas frecuentes

Lo que suelen preguntarme

¿Cuánto cuesta una web o una app?

Depende del alcance. Tras una primera conversación te envío un presupuesto cerrado y detallado, sin compromiso.

¿Cuánto se tarda?

Una web sencilla puede estar lista en pocos días. Una app o un programa de gestión se planifica por fases, con entregas parciales.

¿Trabajas solo en Valencia?

Trabajo en remoto con clientes de toda España. En la zona de Valencia también puedo desplazarme para instalaciones o formación.

¿Puedes conectar programas que ya uso?

Sí. Si tu programa tiene API, exportaciones o base de datos accesible, normalmente se puede integrar y automatizar.

¿Qué pasa después de la entrega?

Ofrezco mantenimiento, mejoras y soporte para que todo siga funcionando y crezca contigo.
