# Web SAT27

Web estática de SAT27 (HTML + CSS + JS, sin dependencias).

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta al repo `quiquew/websat27`.
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. Custom domain: tu dominio → marca "Enforce HTTPS".

## Cambiar el email
Busca `pfjquique@gmail.com` en `index.html` y `assets/main.js`.
